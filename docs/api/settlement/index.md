# Settlement

The settlement endpoints provide information about payment settlements to providers.

**Base URL:** `https://api.netgiro.is/v2/settlement`

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | [`/v2/settlement/list`](./list.md) | List settlements |
| GET | [`/v2/settlement/items/{settlementNumber}`](./items.md) | Get items in a settlement |
